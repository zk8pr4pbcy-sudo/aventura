# Conan GA4 monitoring | مراقبة كونان

## الحالة والنطاق
- الاتصال المجرب: Google Cloud Workload Identity Federation من `main` إلى حساب خدمة `aventura-conan-reader` بصلاحية قراءة GA4 فقط. لا توجد مفاتيح JSON.
- التقرير المجدول: يوميًا الساعة **08:00 صباحًا بتوقيت السعودية** (05:00 UTC)، وقد يتأخر تشغيل GitHub Actions.
- تقرير متجدد عن **آخر 7 أيام مكتملة حتى أمس** مع مقارنة بالأسبوع السابق، وإحصاءات أمس.
- القنوات، المدن (عند 3 مستخدمين نشطين أو أكثر)، الأجهزة، الصفحات، وأحداث نموذج الطلب. لا يستخدم أبعادًا مخصصة غير مضمونة.
- التقرير في **Summary** داخل تشغيل `Conan GA4 daily monitoring` في تبويب GitHub Actions. يعرض بيانات مجمعة فقط.
- عند ظهور مؤشرات تستحق المراجعة، تُنشأ **GitHub Issues** موجهة إلى مالك المستودع. تنبيهات GitHub تعتمد على إعدادات الإشعارات في حساب المستخدم، ولا تُرسل رسائل ChatGPT تلقائيًا.

## شروط التنبيه
1. انخفاض الجلسات الأسبوعية **50% أو أكثر** مقارنة بالأسبوع السابق بشرط أن تكون جلسات الأسبوع السابق **20 جلسة أو أكثر**.
2. عدم تسجيل أي جلسة أمس مع تحقق شرط الحجم السابق نفسه.
3. وجود **5 أحداث** `request_form_started` أو أكثر في الأسبوع وعدم تسجيل `request_completed` خلاله.
4. رصد حدث `request_completed` واحد على الأقل أمس. **الحدث لا يثبت وصول طلب أو إتمام حجز**.
5. فشل تشغيل المراقبة يُظهر GitHub Actions فشلًا، ويحاول إنشاء Issue للمراجعة.

تُمنع تكرارات النوع نفسه ما دام تنبيه GitHub Issue مفتوحًا. أغلقه بعد حل المشكلة لتسمح بتنبيه جديد من النوع نفسه.

## حدود الخصوصية
**المستودع عام؛ ملخصات GitHub Actions والتنبيهات قد تكون مرئية للآخرين.** لا يُرسل النظام بيانات تعريف شخصية أو نصوص نماذج أو مراجع طلبات. لا ينشر أعدادًا في GitHub Issues، لكن ملخصات التشغيل تعرض مقاييس مجمعة. إذا كانت إحصاءات أفنتورا سرية، انقل التشغيل إلى مستودع خاص قبل استخدامه على نطاق واسع.

GA4 قد يحجب زيارات بسبب الموافقة أو إعدادات الخصوصية أو مانعات التتبع؛ البيانات ليست سجلًا مضمونًا لكل زائر. لا يدّعي النظام تتبع رحلات فردية دقيقة أو تحويل أحداث GA4 إلى عملاء مؤكدين.

## اختبار يدوي
1. افتح **Actions → Conan GA4 daily monitoring → Run workflow**.
2. اترك `dry_run=true` للاختبار دون إنشاء Issues.
3. بعد نجاح التشغيل افتح **Summary** للتقرير، ثم اختبر `dry_run=false` إذا رغبت في تفعيل اختبار قواعد التنبيه (قد ينشئ Issue إذا انطبقت الشروط).
4. التشغيل اليومي المجدول يفعّل قواعد التنبيه تلقائيًا.

## استكشاف الأخطاء
- خطأ 401/403: تحقق من صلاحية Viewer لحساب الخدمة على موقع GA4، وشرط Workload Identity على `refs/heads/main`.
- خطأ 429: حدّ طلبات Google API؛ يعيد السكربت المحاولة مرة.
- فشل إنشاء Issue: تحقق من تفعيل Issues في المستودع وصلاحية `issues: write` في GitHub Actions.
- غياب حدث طلب لا يثبت عدم وصول طلب؛ تحقق من نظام استقبال الطلبات مباشرة.
- لا تعدّل كود الموقع أو نموذج الحجز من أجل هذا التقرير؛ المراقبة مستقلة عنهما.
